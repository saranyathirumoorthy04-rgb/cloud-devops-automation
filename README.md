# Automated Cloud Deployment and Monitoring using AWS and DevOps

## Project Overview
This project demonstrates how to build, deploy, and monitor a website using AWS and DevOps tools.

## Objectives
- Build a simple interactive website.
- Manage source code using Git and GitHub.
- Deploy the website on AWS EC2.
- Automate deployment using GitHub Actions.
- Store backups using Amazon S3.
- Monitor infrastructure using Amazon CloudWatch.

## Technologies
- Linux (Ubuntu)
- Git and GitHub
- HTML, CSS, JavaScript
- AWS EC2
- AWS S3
- AWS IAM
- AWS CloudWatch
- GitHub Actions
- Nginx
- Bash scripting
